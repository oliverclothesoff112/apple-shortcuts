# Monk Mode

## Overview

"Monk Mode" is an Apple Shortcuts automation system designed to reduce distractions and create a more focused environment during periods of work.

### The idea is simple:

> Make intentional phone use the habbit over automatic distraction.

---

## The Problem

Smartphones are powerful tools, but they can also provide constant interruptions.

Monk Mode was created to reduce unnecessary distractions during work without requiring the phone to be completely removed or disabled.

---

## How It Works

Monk Mode consists of three shortcuts working together:

### Monk Mode Auto

This is the controller shortcut.

It will check the current Focus mode that is currenly active and then decide whether "Monk Mode" should be activated or deactivated.

### Monk Mode On

Applies the focused environment by adjusting system settings, currently including:

- Work Focus Mode - ON (Focus of your choosing. Redcuing app visibility and noticiation input)
- Silent mode - ON
- Media volume - OFF
- Brightness _ 25%
- Colour filters - ON (Monochrome)

### Monk Mode Off

Restores the normal phone settings when work is complete.

- Work Focus Mode - OFF
- Silent mode - OFF
- Media volume - 65%
- Brightness _ 65%
- Colour filters - OFF

---

## Optional NFC Trigger

Monk Mode can be launched using an NFC tag for a quick physical trigger.

The NFC tag is optional — the shortcut system can also be run manually.

---

## Customisation

Monk Mode is designed to be adapted.

Possible changes include:

- Different Focus modes
- Different brightness levels
- Different sound settings
- Additional automation steps
